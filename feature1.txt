so i created thie repo locally. how do i connect it to a remote repo in github i just created

Make sure you’ve already made the first commit from task 5. Then, in the project folder:

git remote add origin https://github.com/<your-username>/<repo-name>.git
git branch -M main
git push -u origin main
git remote add origin <url> registers the GitHub repo under the name origin. Copy the exact URL from the green Code button on the repo page (HTTPS tab).
git branch -M main renames your local branch to main to match GitHub’s default. Skip it if git branch already shows main.
git push -u origin main uploads the commit and links your local main to the remote, so later pushes are just git push.
Authentication: GitHub no longer accepts account passwords over HTTPS. On Windows and macOS, Git’s credential manager opens a browser login on first push. If it asks for a password in the terminal instead, use a personal access token (GitHub > Settings > Developer settings > Personal access tokens) as the password.

If the push is rejected: that happens when you created the GitHub repo with a README, license or .gitignore, because the remote then has a commit your local repo lacks. Fix it with:

git pull origin main --rebase
git push -u origin main
If the .gitignore conflicts, keep the version Godot generated.

Verify by refreshing the repo page. You should see project.godot, scenes/ and the other files, and no .godot/ folder.

fatal: repository 'https://github.com/DeadManLogan/SKAVO/tree/main/' not found

The remote was added with a browser URL (.../tree/main) instead of the repo URL, and the second remote add failed because origin already exists. Fix the URL on the existing remote:

git remote set-url origin https://github.com/DeadManLogan/SKAVO.git
git remote -v
git push -u origin main
git remote -v should now show https://github.com/DeadManLogan/SKAVO.git for both fetch and push. Your git branch -M main already worked, so the branch name is fine.

If the push is rejected because the remote already has commits (a README or .gitignore created with the repo), run:

git pull origin main --rebase
git push -u origin main
If the .gitignore conflicts, keep the version Godot generated.
