Task 2: DigGrid

Editor steps:

Right-click res://scripts/grid/ → Create New → Script.
Set Inherits to RefCounted, Path to res://scripts/grid/dig_grid.gd, then click Create.
Replace the contents with the code below.

res://scripts/grid/dig_grid.gd

gdscript
class_name DigGrid
extends RefCounted

var width: int
var height: int


func _init(p_width: int, p_height: int) -> void:
	width = p_width
	height = p_height


func is_in_bounds(cell: Vector2i) -> bool:
	return cell.x >= 0 and cell.x < width and cell.y >= 0 and cell.y < height

Notes:

Cells are Vector2i throughout, so the same type works for grid logic, click conversion and later artifact positions.
class_name registers DigGrid globally, so DigSite can call DigGrid.new(8, 8) without a preload.
It extends RefCounted so it’s freed automatically when nothing references it, and it can’t be added to the scene tree by accident.
There’s nothing to see yet. We’ll exercise it for real in task 4, when DigSite builds on it.
